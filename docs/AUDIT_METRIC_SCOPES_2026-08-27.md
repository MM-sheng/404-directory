## 3. 新口径及兼容性

两类接口返回 `metric_definition_version: risk-attribution-v2`：

- `/v1/metrics/risk-evaluations`
- `/v1/metrics/prediction-market-evaluations`

| 分组 | 含义 |
| --- | --- |
| `scopes.total` | 所有记录，包含测试；不是用户成果 |
| `scopes.internal` | 非外部标记或内部身份，包括缺省非外部的本地工作 |
| `scopes.anonymous_external` | 外部但匿名；不能按人去重 |
| `scopes.identified_external` | 外部标记、明确身份类别、非空已存身份摘要 |
| `scopes.unattributed` | 缺失、不支持或不完整的归因，不提升为外部用户 |
| `scopes.external` | 匿名外部与已识别外部的小计，不是额外互斥组 |

恒等式：`total = internal + anonymous_external + identified_external + unattributed`。每组独立计算评估次数、决策分布、回执次数、回执率、报告的行为变化及变化率；工具风险还按组计算动作、结果、规则版本，预测市场按组计算常见原因。

原顶层汇总字段保留全量语义，增加 `legacy_aggregate_scope: total`，避免静默改坏旧客户端。外部归因冲突时优先排除内部标记，`external_evaluations` 也使用这一保守分类。页面和试点脚本已改读分组，外部消费者需同样迁移，不能继续把顶层行为变化当作客户价值。

`qualified_pilot.status = not_measured`，`verified_operators = null`。系统还没有经验证的独立操作者名册，不能用 ID、来源标签或自报结果自动推导试点资格。`null` 表示没有测量依据，不是已经证明有零个操作者。

窗口按评估创建时间取下界；后来补报仍归于原评估窗口和来源。报告者更换身份头不会移动原评估分组。一次性回执重放不增加报告数量。分母为空时比例为 `null`。

## 5. 实现与验证

- 统一分类逻辑：`src/domain/evaluation-metric-scopes.ts`。
- 两类分组聚合：`risk-metrics.ts`、`prediction-market-metrics.ts`，内存和 PostgreSQL 复用同一逻辑。
- 页面：两类风险均分组展示；全量标为不是采用证据，身份称为安装身份而非已验证用户。
- 试点脚本：使用已识别外部预测市场分组；旧版本或不完整响应返回不可用及 null，不回退到混合总量。
- 脚本的身份增长阈值与真正试点资格分开；`first_success_gate_met` 和已验证操作者数保持 null。跨日身份复用放在全体 `identified_usage` 下，不冒充已准入试点复用。

1. 互斥分组总量守恒、身份去重、空分母、异常归因降级。
