### 2.3 预测市场增加证据新鲜度门槛

新规则是保守的产品策略，不是提供方保证，也不是经历史校准的安全概率。

| 条件 | 新行为 |
| --- | --- |
| 市场元数据 `updatedAt` 缺失、无效、达到 24 小时或未来超过 30 秒 | 至少 `review` |
| 交易盘口时间缺失、无效、达到 2 分钟或未来超过 30 秒 | `block` |
| 交易未提供金额 | 至少 `review`，不再返回 `PREFLIGHT_PASSED` |
| 合格的当前证据、金额、监督与地域等其他条件均通过 | 保留正常 `allow` 路径 |

另外：

- 分开抓取时间和提供方观测时间；不再拿“现在刚请求过”冒充盘口源时间。
- 在所有上游请求完成后检查新鲜度，覆盖等待另一来源时过期的情况。
- 无效或超范围时间戳不会触发日期转换崩溃。
- 交易回执有效期不超过新鲜证据的剩余时间，最多两分钟；所有回执仍受一小时上限约束。
- 数据不完整时降低证据完整度置信值；该值仍不是交易安全概率。
- 保守策略可能要求人工复核更新时间较老但内容未变的市场，这是明确的取舍。

回归覆盖正例、过期、缺失、非法、极端数值、未来时钟、精确过期边界、请求期间过期、金额缺失及回执有效期。

文件：`src/domain/prediction-market-risk.ts`、`tests/prediction-market-risk.test.ts`、`docs/PREDICTION_MARKET_PREFLIGHT.md`。

### 2.4 修复启动提示权限契约

MCP `prompts/get` 参数必须是字符串。`evaluate-agent-tool` 现在接受并解析：

- `"public_network"`；
- `"public_network,credentials"`；
- JSON 数组字符串 `'["public_network","credentials"]'`；
- 明确无权限时的 `"[]"`。

解析后传给风控工具的权限仍是数组。缺失、未知、格式错误或超过八项的权限被拒绝，不再默认忽略权限。直接调用 `evaluate_tool_risk` 的 JSON 数组契约不变。

HTTP MCP 回归验证最终提示保留真实权限上下文，错误格式返回错误；打开提示本身不会增加 Agent 激活数。README 已记录这个有意的兼容性变化，旧调用方需要显式传入权限。

文件：`src/mcp/prompts.ts`、`tests/audit-mcp-regressions.test.ts`、`tests/mcp.test.ts`、`README.md`。
